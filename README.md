# LifeTrail — Cloud Build MVP

A privacy-first, Moves-inspired Android prototype.

## Build on GitHub
1. Create a GitHub repository named `lifetrail`.
2. Upload this entire project.
3. Open **Actions** → **Build LifeTrail APK** → **Run workflow**.
4. Open the completed workflow run and download the `LifeTrail-debug-apk` artifact.
5. Extract `app-debug.apk` and install it on the Android phone.

This project is intentionally an MVP. The next engineering milestone is persisting location points locally, clustering them into visits, and generating the Daily Story timeline.
